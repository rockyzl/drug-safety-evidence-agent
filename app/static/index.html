Under the surface
A real agent, with a small research remit.
01
Choose what to look up
LangGraph runs the workflow. The model proposes search queries. A safety brief searches each of three source types: research, FDA communication and prescribing information. Chroma combines embedding similarity with keyword overlap.
02
Check before showing
A second model pass checks whether cited passages support each claim. Code checks reference IDs, exact quoted text and source dates. Claims that fail are withheld from the brief.
03
Leave room for judgment
This is a draft for a researcher to inspect. Model agreement is not independent validation. Differences between studies can remain unresolved.
